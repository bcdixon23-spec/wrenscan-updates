Install

  1. Run the installer. It needs no admin rights and installs just for you (IT departments can install for all users).
  2. Open Wrenscan from the Start menu.
  3. Start a scan. The first one downloads public security data and takes a few minutes.

Wrenscan is new, so Windows may warn you twice while it builds a reputation with Microsoft. Both warnings are normal for new software and go away as more people download Wrenscan.

1. In Edge, if the download says it "isn't commonly downloaded": hover over the download, click …, then Keep, then Show more, then Keep anyway.

2. When you run the installer, the installer and the app are digitally signed by the publisher, and Windows may show "Windows protected your PC": click More info, check that the publisher is Bryce Dixon (Wrenscan's founder, whose verified identity signs every release), then click Run anyway. Please never turn off Smart App Control to install Wrenscan; it can't be turned back on without resetting Windows.

Updates

Wrenscan checks for updates itself and asks before installing. Every update is signed and verified before it runs.

Uninstall

Settings › Apps › Installed apps › Wrenscan › Uninstall. Your scan history stays in %USERPROFILE%\.wrenscan until you delete that folder.
